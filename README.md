# 人生模拟器

一个基于文字选择的人生模拟器网页游戏。

## 功能特点

- 多分支多结局系统，每条分支导向不同结局
- 重生功能，游戏结束后可以选择重生（最多3次）
- 大学选择基于之前的属性和选择
- 年龄精确到每年，时间推进机制
- 抽奖等随机获取财富的机制
- 11种属性：智力、健康、财富、幸福、道德、魅力、运气、声望、艺术、编程、体育
- 8个人生阶段：婴儿期、童年期、青春期、青年期、中年期、老年期、暮年期、结局阶段
- 70+个事件，覆盖整个人生旅程

## 如何运行

### 方法一：直接打开HTML文件
1. 下载或克隆这个仓库
2. 双击 `index.html` 文件，浏览器会自动打开游戏

### 方法二：使用本地服务器
1. 下载或克隆这个仓库
2. 在项目目录中打开命令行
3. 运行 `python -m http.server 8000`
4. 在浏览器中访问 `http://localhost:8000`

## 游戏玩法

1. 选择你的出生家庭，开始你的人生旅程
2. 在每个事件中做出选择，影响你的属性和人生走向
3. 经历不同的人生阶段，直到游戏结束
4. 查看你的结局，并选择是否重生（最多3次）

## 文件结构

- `index.html` - 游戏主页面
- `style.css` - 游戏样式
- `script.js` - 游戏核心逻辑

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
